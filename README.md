# web_project_coffeeshop_es
# Triple Espresso

Landing page de la cafetería Triple Espresso, desarrollada como proyecto del Sprint 3 del bootcamp de Desarrollo Web de TripleTen.

## Descripción y funcionalidad

La página presenta la cafetería y permite a los visitantes reservar una mesa. Incluye:

- **Encabezado** con navegación interna a las secciones de reserva y contactos, título, descripción, horarios y dirección.
- **Sección de reserva** con un formulario validado por el navegador: nombre, número de comensales (1–8), fecha y hora, correo electrónico y aceptación de los términos de uso.
- **Pie de página** con logotipo, enlaces a redes sociales y derechos de autor.
- **Estados hover** con transiciones en los enlaces de navegación, el botón del formulario y los enlaces del pie de página.

## Tecnologías y técnicas

- **HTML5 semántico:** `header`, `main`, `section`, `footer`, `nav`, listas y formularios accesibles (`label` + `for`/`id`, atributos `required`, `min`, `max`, `placeholder`).
- **CSS3:** Flexbox para la alineación, posicionamiento `relative`/`absolute` con `z-index`, pseudoclases (`:hover`, `:checked`) y pseudoelementos (`::placeholder`), transiciones.
- **Metodología BEM** para nombrar las clases.
- **Estructura de archivos** organizada en carpetas (`images/`, `styles/`).
- **Google Fonts** (Inter y Noto Serif) con fuentes de reserva.
- **normalize.css** para unificar los estilos entre navegadores.
- **Git y GitHub** para el control de versiones.
- **EditorConfig y Prettier** para el formato del código.
